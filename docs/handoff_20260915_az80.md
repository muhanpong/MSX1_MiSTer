## 2. What it took (all in `rtl/msx.sv`, `MSX1.sv`, `rtl/peripheral/az80_clkgen.sv`, `rtl/cpu/az80/`, `MSX1.sdc`)
1. A-Z80 data pins made unidirectional; strobe pull-up emulation in reset.
2. az80_clk phase-locked to clk21m (7.16 = 2+1). Boundary paths stated as real max delays, not `-end N`.
3. SDRAM read pacer `az_rd_pace_n` on clk_sdram behind a 2-flop synchroniser (`az_win_s1/s2`).
4. **SDRAM request delay `sdram_ce_sr` (capture on clk_sdram edge 3–4)** — A-Z80 drives its address on the MREQ edge;
   the old `*sdram*ch2_* -end 6` silently relied on T80's half-T-state address lead. This was the boot killer
   (first page change `OUT (AB),82` → fetch 042A returned FF → RST 38h storm), found with the JTAG trace.
5. **M1 wait generated on A-Z80's falling edge** (`az_m1w_n`); the 74LS74 pair on ce_cpu missed the Tw by phase (+15%).
6. Handshake on clk_sdram (hit release edge 6 < 10.7 sample edge 8); clk21m quantisation cost a Tw per read (−8%).
7. False paths by mutual exclusion (T80s ↔ A-Z80, T80s → A-Z80-only synchronisers, use_t80, OSD speed bits).

## 5. Pitfalls (each cost a build or a wrong conclusion)
- **ISM dumps come out highest address first** — two traces were read time-reversed before `parse_aztrace.py` got `raw[::-1]`.
- Quartus volume (`nvme0n1p5`) unmounts on reboot: `udisksctl mount -b /dev/disk/by-uuid/0eb4bebc-0644-4c2f-9a97-ddca5afcd8f3`.
- Never pipe a build through `tail`; never deploy from a chain that can outlive a killed fit.
  **`MSX1_20260915c_osdcore.rbf` is MISLABELED** (identical to `b_azm1w`, md5 192ab48d327f) — kept, never reuse the name.
- A long combinational signal sampled by several clk_sdram flops: synchronise first, relax only the first flop.
- TimeQuest per-clock ps rounding (4×11.641 ≠ 46.566) reports coincident edges as 0.000/0.002 ns setup — state the real
  requirement with `set_max_delay`; an `-end 2` gave 93 ns on falling-edge flops (checked by `relations.tcl`).
- Bench memory models need the real latency (edge capture + delay + address settle), and verify the settle-model index.
- A-Z80 ÷1 (21.477) is dead: 0/7 fits — do not retry.
- RBF naming `MSX1_<YYYYMMDD><letter>_<desc>.rbf`; RBFs are never deleted.
