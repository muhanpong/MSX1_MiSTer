# 실기 체크리스트 — `MSX1_20260830a_pana40h`

빌드 트리 = `9baa294` + 터보 세션의 미커밋 P3. 타이밍 worst setup +0.243 ns, 미충족 0건.
27a 이후 새로 들어간 것: **Panasonic I/O 40H/41H 터보 스위치**(`dev_matsushita`),
**FS-A1FX 팩**(+1/2/4MB), FS-A1WX·FX **WD2793 디스크 대체**.

이 빌드가 27a를 대체하므로 `docs/hwtest_20260827a.md`의 미완 항목(A·D·E)이 여기로 넘어옵니다.

## ✅ 확인됨 (2026-08-30, FS-A1FX)

- [x] **소프트 터보 동작** — 포트 40H/41H로 속도 전환
- [x] **DOS1 부팅** — WD2793 대체가 실기에서 통함 (TC8566AF 미모델링 우회)
- [x] **Konami 매퍼 ROM 게임 정상**
- [x] *(함의)* **A1 Cockpit이 부팅을 가로채지 않음** — BASIC/DOS까지 갔다는 게 곧 증거.
      41H bit7=1(펌웨어 스위치 OFF)이 의도대로 동작했다는 뜻.

## ☐ 남은 것 — 새 기능

우선순위 순.

- [ ] **음성 대조: 장치 없는 머신은 응답하면 안 됨**
      Sony HB-F1XV 등에서 `OUT &H40,8:PRINT INP(&H40);INP(&H41)` → **`255 255`**
      ← 이게 실패하면 머신별 게이팅(`<device typ="MATSUSHITA">`)이 깨진 것.
      **양성만 확인하고 음성을 안 보면 검증이 아님.**
- [ ] **OSD 우선순위 규칙** — OSD `CPU Speed`를 7.16 또는 10.7로 둔 채 `OUT &H41,0`
      → **느려지면 안 됨**(사용자 결정 규칙: 포트는 올리기만 함)
- [ ] **OSD 터보가 소프트에 안 보여야 함** — OSD로 터보를 켠 상태에서
      `OUT &H40,8:PRINT INP(&H41)` → bit0이 **여전히 1**(=250이 아니라 251)
      ← MGSDRV 오보정 방지 장치. 이게 깨지면 PSG가 5도 어긋나 들린다
- [ ] **FS-A1FX의 MSX-MUSIC** — 실기 FX엔 없는 걸 의도적으로 넣은 것이라 FM 소리 확인
- [ ] **FS-A1FX 한자** — FX 한자 폰트는 WX와 다른 ROM(128KB vs 256KB)
- [ ] **FS-A1WX** — 위 확인은 전부 FX에서 한 것. WX의 DOS1·터보는 아직
- [ ] **FX 매퍼 변형 1MB / 2MB / 4MB** — 기본판과 `block_count` 1바이트만 다르지만,
      4MB는 DDR3 슬롯 간격 이슈와 얽힐 수 있음(`docs/TODO_boot_flakiness.md`)

## ☐ 남은 것 — 27a에서 넘어온 것

- [ ] **A. 회귀** — 기본 설정 소리가 26d/27a와 같게 들리는지
- [ ] **D. SCC+ ch5 음색** — ch5가 ch4 파형을 쓰던 구간이 사라졌는지.
      재생 중 `0xA000~0xBFFF`에 bit7 없는 뱅크를 페이징할 때 나던 증상.
      **세 빌드 연속 미검증** — 확인해야 `docs/TODO_scc_divergences.md` D5를 닫는다
- [x] **E-1. 터보에서 OPLL 정상** (2026-08-30) — 터보 빌드마다 깨지던 기존 결함이
      실기에서 해소됨. 근본은 IKAOPLL 임시래치 1개 + 18슬롯 회전 커밋이었고,
      드라이버가 SW 지연으로 지키던 데이터시트 간격(주소 12 / 데이터 84 XIN)이
      터보에서 루프 축소로 무너지던 것. 수정 = msx_slots의 TURBO OPLL PACER.
      **그 pacer가 실기에서 통한다는 첫 확인.**
      증거: SCMD 1.10.4 / Out Run -Passing Breeze- 를 OSD `CPU SPEED: 10.7MHZ` 로 재생.
      채널 미터에 PSG 3 / SCC 10 / FM 10 이 전부 살아 있음 = **10.7MHz 터보에서
      OPLL 과 SCC 가 동시에** 정상. (Out Run 은 FM+SCC 곡 — PSG/PCM 기여 0,
      `project_scmd_outrun_levels` 실측.)
- [ ] **E-2. turbo OFF에서 기존 게임** — FX Konami 게임이 돌았지만 그때 터보가
      켜져 있었는지 미확인이라, 별도로 봐야 함
- [ ] **E-3. P3 클로즈드루프 read 속도·안정성** — ★이게 확인돼야 **터보 세션이
      P3를 커밋**한다(현재 의도적 미커밋 보류 중)
