# 실기 체크리스트 — `MSX1_20260827a_volladder`

두 세션의 작업이 처음으로 한 빌드에 모입니다. 26d 실기 결과가 아직 안 나온 상태라
이 목록이 26d 항목까지 포함합니다.

빌드 트리 = `9bb5db4` + 터보 세션의 미커밋 P3(26d와 동일 내용).

---

## A. 회귀 — 먼저 이것부터

기본 설정(아무것도 안 건드림)으로 부팅.

- [ ] **부팅 정상**, 부트로고 뜸
- [ ] 기존 게임 하나 정상 구동
- [ ] **소리가 26d와 같게 들림** ← 중요. 볼륨 메뉴를 전부 갈아엎었지만
      **기본값의 실제 게인은 안 바뀌었습니다**:
      | 음원 | 26d 실제 | 27a 실제 |
      |---|---|---|
      | PSG / OPLL / SCC | 0 dB | 0 dB |
      | OPL4 FM | +4.01 dB (라벨은 `+8dB`였음) | +4.01 dB (라벨 `+4dB`) |
      | OPL4 PCM | −11.97 dB | −12.04 dB |
      다르게 들리면 회귀입니다.

## B. 볼륨 메뉴 — ✅ 실기 통과 (2026-08-28). 라벨 = 실제 게인

`Audio settings` 페이지. 레벨미터로 보시는 게 가장 확실합니다.

- [x] 다섯 메뉴가 **같은 눈금**: `0, -2, -4, -6, -8, 0, +2, +4, +6, +8` (FM만 `+4`에서 시작)
- [x] 한 칸 움직일 때 **실제로 2 dB** 변함
- [x] `0dB`가 **감쇠 없음**(유니티)과 일치 — PSG/OPLL/SCC에서 확인하기 쉬움
- [x] PCM `0dB`가 이 음원의 정상 레벨로 들림(= 26d 기본값과 같음)
- [x] PCM을 `+8dB`까지 올리면 커지되, 큰 곡에서는 클립할 수 있음 — 정상

## C. 서브슬롯 확장 — ✅ 실기 통과 (2026-08-28, `20260827a_volladder`)

- [x] `SLOT A sub-slots = On` → `Sub-slot 0 = ROM`(게임 로드) → 게임 정상 구동
      ★슬롯이 확장되면 그 슬롯의 `0xFFFF`가 서브슬롯 레지스터가 되므로
      **게임이 도는 것 자체가 핵심 검증**입니다
- [x] BASIC에서 `PRINT HEX$(PEEK(&HFCC2))` → **bit7(`&H80`)이 서야** 함
      (`EXPTBL`. 26c에서는 안 섰습니다)
- [x] `Sub-slot 1 = FM-PAC` 추가 → 게임 그대로 돌고 **FM 음악 남**
      ← 비-0 서브슬롯에 장치를 올리는 첫 주행
- [x] `Sub-slot 2 = ROM`(0·1 비움)으로도 부팅 — 빈 서브슬롯 건너뛰기와
      서브슬롯별 매퍼 검출 확인
- [x] `Off`로 되돌리면 기존 메뉴 복귀

> 메뉴가 전부 루트로 펼쳐져 보이면 CONF_STR 버그가 아니라 펌웨어 **flat 모드**입니다.
> OSD에서 백틱 `` ` `` 을 누르면 토글됩니다. 구분법: 코어 자체 `Video settings`·
> `Audio settings`도 같이 펼쳐졌는지 보면 됩니다.

## D. SCC+ ch5 음색 (D5 수정, 26d부터)

- [ ] ch5가 ch4와 다른 파형을 쓰는 곡에서, **중간에 ch5가 ch4처럼 들리는 구간이
      사라졌는지**. 재생 중 `0xA000~0xBFFF`에 bit7 없는 뱅크를 페이징할 때 나던 증상입니다.
