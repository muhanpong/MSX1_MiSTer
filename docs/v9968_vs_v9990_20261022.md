# V9968 (+Geo3D) vs V9990 비교 (2026-10-22)

V9968 쪽은 실측(rbf 7fcf4fe, SEED 11, TIMING PASS)이고, V9990 쪽은 2026-10-20 조사와 단독 합성 값이다.
출처: `docs/plan_v9968_integration.md` §0c, `docs/evidence_20261020/vdp_area.txt`(`tools/sdram128/vdp_area.sh`),
`output_files/MSX1_V9968.fit.rpt`(7fcf4fe).

## 1. 구현과 상태

| 항목 | V9968 (+Geo3D) | V9990 |
|---|---|---|
| 기준 RTL | HRA! V9968_Cartridge (Verilog). Geo3D v2.0.0 (Alex Moncks) | **rampa069/v9990** (VHDL, F18A 3.0 포크에서 분리), 조사 시점 36170c5 |
| 라이선스 | V9968: 파일 헤더 3조항 + 상업 이용 제한 (저장소 LICENSE는 MIT). Geo3D: MIT | BSD-3 (파일 헤더만, LICENSE 파일 없음) |
| 상태 | **통합 완료.** 보드 동작, rbf 3개. upstream 버그 3건 수정, 4번째(1클럭 늦은 status 래치) 수정 중 | **미통합.** 조사와 단독 합성만 |
| 기능 범위 | V9958 상위 호환 + 확장. Geo3D 3D 엔진 | B0-B4, B7 전 색 모드, 스크롤/롤, 커서, P1/P2 + 스프라이트, 명령 전부. B5/B6는 매뉴얼 기준(실칩 미대조) |
| 검증 수단 | VPROBE(fullsys), sim/v9968_vram 벤치, openMSX msx2pp 대조 | upstream에 NVC + cocotb, openMSX 대조 모델 |
| 통합 선례 | HRA! 카트리지 (Tang Nano 20K) | **BigMist ZEMMIX** (MiST 계열, Quartus): `misc/v9990_bus.vhd` (포트 60-6Fh, wait_n), `sdram2.sv` (OPL4 웨이브와 VRAM 공유) |
| 다른 후보 | - | buppu3/tnCart: 2025-06 이후 정지, B0, B5/B6, 커서 EOR, R#16, 한자 ROM 미구현 (herraa1이 HRA! 카트에 이식, 실기 4대 동작). VWarlock / taupter: RTL 거의 없음, 제외 |

## 2. 클럭, VRAM, 포트

| 항목 | V9968 | V9990 |
|---|---|---|
| 동작 클럭 | 85.909 MHz (clk_vdp). Geo3D 엔진 42.95 MHz (clk_geo) | 42.95 MHz, 라인당 2736클럭 |
| PLL 관계 | 128.86 x 2/3: VCO 515.45 MHz / 6 | 128.86 / 3: VCO / 12, **지금의 clk_geo (outclk_3)와 같은 출력** |
| VRAM | 256 KB, SDRAM bank 3 (sdram_tdm V 슬롯) | 512 KB. M10K로는 불가 (4 Mbit, 남는 M10K 약 1.2 Mbit) -> **SDRAM V 슬롯 + 캐시** (4워드 라인, 스프라이트 속성은 BRAM 사본) |
| CPU 포트 | 98h-9Fh (Geo3D 9Dh/9Fh) | 60h-6Fh |
| 라인 주기 | 63.7 us | 63.7 us (= V9958 1368클럭 at 21.48 MHz) -> 프레임 동기를 맞추면 슈퍼임포즈 가능 (미검증) |

## 4. 빌드 조합 (ALM 추정 = 단독 x0.77 .. 단독 그대로)

| 빌드 | ALM | 점유율 | M10K | DSP |
|---|---|---|---|---|
| V9958 (기존, 03a1f21) | 30,118 | 72 % | 435 | 53 |
| V9968만 | 31.9k - 32.7k | 76-78 % | 331 | 61 |
| **V9968 + Geo3D** | 추정 34.2k - 35.8k -> **실측 33,782** | **81 %** | RAM 블록 323 | 67 |
| V9990 (+캐시) | 32.8k - 33.9k | 78-81 % | 335 | 54 |
| V9958 + V9990 | 34.0k - 35.2k | 81-84 % | 452 | 54 (슈퍼임포즈 믹서 제외) |

- 추정에 빠진 것: SDRAM 브리지, PLL 출력, CPU 버스 어댑터, 영상 먹스.
- x0.77은 V9958 하나에서 잰 단독 대 코어 비율(1,483 -> 1,140)이다. 측정점 하나짜리 추정이다.
- V9968 + Geo3D 실측(33,782)은 추정 범위 아래쪽 바깥이다. 추정이 보수적인 쪽으로 틀렸다.

## 5. 사용자 방향 (2026-10-20)

- 빌드 선택지: **V9958(+TMS9918) / Geo3D + V9968 / V9990**. 15 kHz 출력은 고려하지 않는다.
- V9958을 늘 넣을 만큼 자원이 남으면 V9990 슈퍼임포즈(V9958 화면 위에 V9990)를 검토한다.
- V9990 기준 후보는 rampa069/v9990 (가장 완전하고, 테스트가 있고, 같은 Quartus/MiST 계열 통합 선례가 있음).
