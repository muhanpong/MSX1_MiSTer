## 2. Build structure

- `MSX1.qsf` — default build: ESE VDP (V9958) + TMS9918, unchanged behaviour.
  `rtl/video/video.qip` is now listed in `MSX1.qsf`, not `rtl/files.qip`.
- `MSX1_V9968.qsf` — generated by `tools/sdram128/mk_v9968_qsf.sh` from `MSX1.qsf`
  (`VERILOG_MACRO MSX_V9968=1`, `rtl/video/video_v9968.qip` instead of `video.qip`).
  Separate revision because the V9968 Verilog module and the ESE VHDL entity are both `vdp`.
  Regenerate it after editing `MSX1.qsf`.
- V9968 build = V9968 for **every** machine type, MSX1 included (user 2026-10-21:
  "9918 빼버려요").  No BRAM VRAM in this build.  Video always from the V9968
  (31.4 kHz, `CLK_VIDEO = clk_vdp`, scandoubler and vcrop off).
- PLL `rtl/pll_v9968.v`: 128.86 / 85.909 / 21.48 MHz, one VCO, phase 0.
- `v9968_link #(.RELEASE_PH(5))` in `MSX1.sv`: the V9968 leaves reset on a fixed TDM
  cycle.  Sweep: 12 phases land on 8 clk_vdp release edges; only one edge works
  (phases 4/5 in fullsys, 5 in `sim/v9968_vram`).  Keep 5.
- `rtl/video/v9968_bus.sv`: CPU I/O 98h–9Fh → V9968 host bus.  `done` is a **level**
  (`st == S_DONE`).  The earlier toggle (`done_tog`, in `1a8323d`) deadlocked a
  handshaked CPU: a write can finish 2 clk_vdp after the strobe, before the clk21m edge
  that took the reference value.
- `msx.sv` WAIT for a handshaked CPU (`cpu_paced`: turbo T80s, NextZ80, resume guard):
  spacing pacer grant (`vdp_grant_d`, VDP_GAP38 or the R800 OSD gap — kept for ASO's
  split screen) **and** transaction done.  Stock CPU never waits; `v99_late_cnt` counts.

## 3. Evidence (fullsys, `sim/fullsys/vprobe/run.sh`, FS-A1FX, tdm128)

VPROBE replaces the BIOS (a BIOS boot is still in its RAM test at 600 ms, ESE build
too).  Phases: 1 port-98h VRAM write/read (00000h, 1C000h, alias check), 2 SCREEN 5
HMMV + CE + readback, 3 two VBLANKs with display on, 4 IM 1 interrupt.  The probe
skips 0180h–018Bh: `turbor.sv` overlays CHGCPU there in non-turbo-R packs too.

Results are in `docs/evidence_20261020/v9968_s5_vprobe.txt` (first run) and
`docs/evidence_20261020/v9968_s5b_suite.txt` (this commit).  Summary:

| Run | Result | Want |
|---|---|---|
| stock Z80 | PASS | PASS |
| T80s 21.48 MHz (`+zspeed=4`) | PASS | PASS |
| VG-8020 (MSX1), stock (before phase 4 existed) and T80s 21.48 MHz | PASS | PASS |
| `-DV99_RELPH=6` | FAIL (first read never answered) | FAIL |
| `-DV99_MUT_NOWAIT` + 21.48 MHz | FAIL (1 read error of 3072) | FAIL |

PASS runs: every VRAM read answered at exactly +8 clk_vdp, shadow mismatches 0, link
drops 0, late CPU reads 0.

Not a fault: VRAM writes < port-98h writes at 21.48 MHz (2048 accepted, 1536 to VRAM).
The V9968's `vdp_command_cache` (8 lines, write-back) merges bytes of one 32-bit word.

## 4. Open / weak

1. **NOWAIT control is thin** (1 error in 3072): at 21.48 MHz the spacing pacer
   (1.49 µs) already covers the transaction (≤ 0.44 µs).  Stronger control: a mutant with
   the spacing pacer also off, NOWAIT vs WAIT.  Offered to the user, not done.
2. NextZ80 (`use_nz`) not run through VPROBE (R800 gap 10.1 µs).
3. ESE build: only compiled + 1 ms after these `msx.sv` edits (all inside
   `ifdef MSX_V9968`, the ESE branches unchanged).  A longer ESE fullsys run or the
   existing regressions before relying on it.
4. `sim/sdram_tdm` regression not re-run after the `tdm_run` port (`1a8323d`).
5. Not seen by sim: video path (CLK_VIDEO 85.9 MHz, HDMI/scaler at 31.4 kHz), BIOS
   logo boot (long run), openMSX VRAM comparison (with S6).
6. Next real step: Quartus build of `MSX1_V9968` + STA (S7: three domains,
   `field_race.tcl`, `relations.tcl`) — **ask first**.  Quartus 17.0 only on this
   machine; one job at a time; `git checkout -- MSX1.qsf` after `project_open`.

## 5. User decisions this session

- TMS9918 out of the V9968 build (default build keeps V9958 + TMS9918).
- No PAL forcing in the V9968 build (31 kHz; MSX1 PAL machines will run at 60 Hz).
- Earlier: build options V9958(+TMS9918) / Geo3D+V9968 / V9990; 15 kHz not a concern.

Still for the user: MSX1 colours = V9968 reset palette (MSX2 standard palette, as an
MSX2 shows MSX1 games); OSD items that do nothing in this build (border, VDP ID,
scandoubler); 32 MB upload limit vs the V9968 VRAM bank (decision 4); Geo3D.

## 6. How to run

```
OUT=/tmp/vp sim/fullsys/vprobe/run.sh                 # 5 runs, ~45 min, RESULT PASS/FAIL
V9968=1 XDEFS=-DVPROBE EXTRA="+kprobe=$PWD/sim/fullsys/vprobe/vprobe.hex [+zspeed=4]" \
   OUT=/tmp/x sim/fullsys/run_preload.sh tdm128 <pack.MSX> 250
```
Assemble the probe: `~/data/knightmare/tools/sjasmplus --raw=vprobe.bin --lst=vprobe.lst
vprobe.asm && xxd -p -c1 vprobe.bin > vprobe.hex` (in `sim/fullsys/vprobe/`).
