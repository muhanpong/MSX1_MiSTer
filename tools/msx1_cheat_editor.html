MSX1_MiSTer — Cheat Editor

Edit cheats once, export to two targets:
(a) raw .cht — for this core's custom F9 loader (4 bytes/cheat {addr_lo, addr_hi, value, flags}, 4-way set-associative engine, 512 sets × 4 ways).
(b) MiSTer-standard .zip of .gg files — for the standard MiSTer OSD cheat menu, where each cheat shows by its description and can be toggled on/off in the OSD itself.

MiSTer-standard .zip export

The .zip contains one .gg file per cheat; the filename (minus .gg) becomes the cheat's description shown in the OSD. All valid rows are exported (invalid addr/value rows are skipped) — the MiSTer OSD shows each one by its description and lets the user toggle it on/off there, so the per-row On state above is only used for the raw .cht path.

Place the file at /media/fat/cheats/<CoreName>/<romname>.zip. The base name must match the loaded ROM file name (or the ROM's CRC) for MiSTer to auto-find it.

How to use
  1. Add cheats manually or Load .mcf / Load .zip to import a whole game's set. e.g. fuel = address DC78, value 80.
  2. Custom F9 path — Download .cht and copy it to /media/fat/games/MSX1/. In the core OSD: Load Cheats → pick the file, then set Cheats → On. All rows (on and off) are written; only the On ones activate on hardware. The 4-way conflict warning above applies here.
  3. MiSTer-standard OSD path — Download .zip and place it at /media/fat/cheats/<CoreName>/<romname>.zip (base name must match the ROM name or its CRC). The standard cheat menu lists each cheat by its description and lets you toggle each one on/off in the OSD. All valid rows are exported regardless of the On column.
