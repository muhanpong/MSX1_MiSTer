MSX1 치트 에디터

메모리 주소에 값을 고정하는 치트를 만들어 MiSTer용 파일로 내보냄. 예: 주소 DC78에 값 80 = 연료 고정. 게임별 치트는 blueMSX .mcf에서 불러오는 게 빠름.

⬆ .mcf 불러오기 (blueMSX) ⬆ .cht 불러오기 ⬆ .zip 불러오기 (MiSTer)
# 켜기 이름 주소 (hex) 값 (hex)
치트 추가를 누르거나 .mcf / .cht / .zip을 불러올 것.
주소 0000–FFFF · 값 00–FF. 이름을 한글로 쓰면 파일엔 저장되지만 MiSTer OSD 글꼴에 한글이 없어 기기 화면에선 깨져 보임.
넣는 곳켜는 법
표준 .zip (추천) /media/fat/cheats/MSX1/<롬파일명>.zip — 이름을 롬 파일과 맞춰야 인식 OSD → Cheats에서 개별 on/off. 켜기 체크 무관, 유효한 행 전부 포함
.cht /media/fat/games/MSX1/ — 이름 자유 OSD → Load Cheat → Cheats On. 켜기 체크된 행만 동작, 아래 충돌 경고는 이 경로 전용
