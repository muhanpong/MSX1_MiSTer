MSX1 치트 에디터

MiSTer MSX1 코어용 치트 파일을 만들고 고치는 도구입니다. 이 페이지 하나로 전부 동작하며, 인터넷 연결이 필요 없습니다.

치트가 뭐냐면 — 게임 메모리의 특정 주소에 원하는 값을 계속 써 넣어 고정하는 것입니다. 예를 들어 어떤 게임의 연료가 주소 DC78에 있다면, 거기에 80을 계속 써서 연료가 줄지 않게 만드는 식입니다. 주소와 값은 게임마다 다르며, 보통 blueMSX용 .mcf 치트 모음 파일에서 가져옵니다.

만든 치트를 내보내는 길은 두 가지입니다. 뭘 골라야 할지 모르겠다면 표준 .zip을 쓰세요.

표준 .zip추천

MiSTer 공통 치트 메뉴용. OSD의 Cheats 메뉴에 치트가 이름별로 나열되고, 거기서 하나씩 켜고 끌 수 있습니다.

복사 위치: /media/fat/cheats/MSX1/<롬파일이름>.zip
— zip 이름이 롬 파일 이름과 같아야 자동으로 인식됩니다.

아래 표의 켜기 체크와 무관하게, 유효한 행이 전부 들어갑니다 (켜고 끄는 건 OSD에서 하니까요).

.cht이 코어 전용

이 코어의 자체 로더용. OSD의 Load Cheat으로 파일을 고르고 Cheats → On으로 한꺼번에 켭니다.

복사 위치: /media/fat/games/MSX1/ (파일 이름은 자유)

아래 표의 켜기 체크가 그대로 저장되어, 체크된 치트만 하드웨어에서 동작합니다. 치트가 아주 많으면 아래 충돌 경고를 확인하세요.

1치트 입력하기

⬆ .mcf 불러오기 (blueMSX) ⬆ .cht 불러오기 ⬆ .zip 불러오기 (MiSTer)
# 켜기 이름 (OSD에 표시될 설명) 주소 (16진수) 값 (16진수)
아직 치트가 없습니다. 치트 추가를 누르거나, 위에서 .mcf · .cht · .zip 파일을 불러오세요.
주소는 0000~FFFF, 값은 00~FF 범위의 16진수입니다. 잘못 입력한 칸은 빨간 테두리로 표시됩니다.

2파일로 내려받기

.cht 파일 내용 미리보기
(비어 있음)

3MiSTer에 넣고 켜기

  1. 표준 .zip을 받았다면 — SD 카드의 /media/fat/cheats/MSX1/ 폴더에 넣되, 파일 이름을 게임 롬 파일 이름과 똑같이 바꿔 주세요 (예: 롬이 Nemesis2.rom이면 → Nemesis2.zip). 게임을 켠 뒤 OSD(F12)의 Cheats 메뉴에서 원하는 치트를 하나씩 켭니다.
  2. .cht를 받았다면 — /media/fat/games/MSX1/에 넣고, OSD의 Load Cheat에서 파일을 고른 뒤 Cheats를 On으로 두면 (위 표에서 체크했던 치트만) 바로 동작합니다.
  3. 치트를 바꾸고 싶으면 이 페이지에서 파일을 다시 불러와 고친 뒤 같은 자리에 덮어쓰면 됩니다. .cht에는 이름이 저장되지 않으니, 이름을 지키려면 .zip이나 .mcf를 보관하세요.
